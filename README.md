# IncomeTaxCalculatorIndia

Your friendly, educational Indian Income Tax calculator and teacher for first-time taxpayers.

## About This Tool

IncomeTaxCalculatorIndia is a single-page web tool designed specifically for **first-time taxpayers, newbies, and dummies** in India. 

It explains complex tax concepts using simple language, strong analogies, and practical tips while accurately calculating your tax liability for FY 2025-26 / AY 2026-27.

## Key Features

- Step-by-step guided experience (5 clear steps)
- Strong analogies and deep explanations for every term
- Clear comparison between New Tax Regime and Old Tax Regime
- Support for multiple employers (changing jobs)
- Section 80C (₹1.5 lakh limit), HRA exemption, and Section 80D
- Live preview and rich "Your Tax Story" results page
- Guidance on Form 16, AIS, and Form 26AS with official links
- Common mistakes and legit tax-saving tips
- Fully offline — works after saving the HTML file

## How to Use

1. Download or copy the `indiantaxcalculator.html` file
2. Open the file in any modern browser (Chrome recommended)
3. Follow the 5 steps
4. Enter your details and see your complete tax story
5. Use the results and checklist to file on the official portal

## Important Notes

- This is an **educational tool** only
- Always verify final numbers on the official website: https://www.incometax.gov.in
- Not a substitute for professional CA advice in complex cases
- Calculations are based on AY 2026-27 rules
